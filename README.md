# 🌸 Iris Flower Classification

## 📖 Overview

This project is part of my **CodeAlpha Data Science Internship**. It uses Machine Learning to classify Iris flowers into three different 
species based on their sepal and petal measurements.

---

## 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## 📊 Dataset

The Iris dataset was loaded directly from **Scikit-learn (`sklearn.datasets`)**, so no external dataset file is required.
